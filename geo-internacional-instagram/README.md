# GEO Internacional Instagram

Área pública para alojar imagens destinadas ao Instagram @geointernacional.

## Estrutura
- `campaigns/YYYY-MM/` — imagens finais em JPEG, prontas para publicação.
- `latest.json` — referência para a campanha mais recente.

## Regras de publicação
- Formato preferencial: 1080×1350 (4:5).
- JPEG, até 8 MB por imagem.
- 2 a 10 imagens por carrossel.
- As imagens aqui alojadas são públicas para permitir publicação automática via Windsor.ai/Instagram.

Arquivo de trabalho complementar: pasta Google Drive `GEO Internacional Instagram`.
